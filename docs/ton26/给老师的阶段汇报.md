## 1. 当前目标
评估 PLUM（ICNP'24）的两条期刊扩展线（带宽预测、Green-PLUM）能否合并为一篇可投 IEEE Transactions on Networking（TON）的论文，并明确差距。

## 2. 原 PLUM 基础（已发表 ICNP'24）
WLAN 半双工瓶颈下，用应用层双向带宽协调（SLSQP + Hossfeld QoE 效用 + entangled state machine，不修改 MAC）替代被动 MAC 公平分配。结果：平均用户码率较最优 baseline +48–59%。基础扎实，有理论（Theorem 1/2）+系统+实验。

## 3. 当前新增设计
- **预测增强**：Transformer 带宽预测前瞻参与容量观测与分配（`--mlpred`）。
- **Green-PLUM**：分配时纳入设备剩余电量 SoC 与温度，对低电/过热设备降码率（`--green`/`--obsdeliv`），换存活与温度稳定。有三套实现（数值模型/solver 闭环/trace-driven），须严格区分。

## 4. 已有实验进展（均经脚本复核）
- **预测（可信）**：model-based Wi-Fi, N∈{3,4,6}, **10 seeds** → 吞吐 **+17.04%**、QoE **+6.73%**。可复现。
- **Green trace-driven（初步）**：N=8, **仅 3 seeds** → Vanilla/Plum/Green 平均下行 4.75/9.33/5.40 Mbps；存活 1.3/2/4（8台）；峰温 92/60/47°C。Green 用约 42% 吞吐换续航/降温。
- **Pred+Green 联合：无任何结果。**
- 诚实代价：Green 画质换续航，非无条件提升 QoE。

## 6. 当前判断：是否有潜力形成一篇 TON
**有潜力，但目前不是一篇可投论文。** 预测与 Green 各有正向但局部结果，二者**尚未形成统一系统**（无联合实验）。统一叙事"预测驱动、能耗感知的双向协调"成立，需要联合实验证据。

## 7. 最大的三个风险
1. **统计不足**：Green 仅 3 seed，全部结果无置信区间。
2. **能耗模型可信度**：trace-driven 出现 92°C、单设备 20W 的模型 artifact（手机应~4W），物理不合理。
3. **统一性未证实**：Pred+Green 无联合实验；预测失效边界（trace-driven 结构性不敏感）机理未解释。

## 8. 下一阶段最重要的 3–5 项工作
1. Pred+Green 联合实验（五对照两平台）——决定能否统一。

3. 预测失效边界：误差注入 + 机理解释 +（可选）扰动界理论。
4. 能耗模型修复：温度/功率异常校准 + 至少 1 项真机或功率计校准。
5. 取得 seq312 全文，先判断问题、输入输出和可复现性，再决定作为 related work 还是 baseline。
