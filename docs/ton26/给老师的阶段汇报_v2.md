## 1. Plum 当前做到哪里(与 v1 相同,一句话版)

ICNP'24 会议版完整(理论+系统+三平台实验,+48–59%);期刊两条扩展线中,**Prediction 有可信但口径受限的正结果**(model-based Wi-Fi、N∈{3,4,6}、10 seeds:吞吐 +17.04%、QoE +6.73%),**Green 只有初步方向性结果**(trace-driven、N=8、仅 3 seeds;存活 1.3→4/8、峰温 92→47°C,但 92°C/20W 是模型 artifact 待修);**Pred+Green 联合实验为零**。

## 2. 其他会议论文通常如何扩到 ToN(本轮新增,案例实证)

- 14 组已验证案例(ICNP:GEMINI、Virtual Filter、AlignTrack、Proteus、GeneWave、CDN Transit;SIGCOMM/NSDI:TACK、Aeolus、Zhuge、Pudica;INFOCOM/CoNEXT:BOLA、FEDL、AoI 调度、OLIA)归纳出五型增量:**新模块 / 新理论 / 新场景应用 / 部署强化 / 实验完备化**;强案例都是"一个会议版中出现次数为 0 的结构性新轴 + 完备实验",**纯加长版没有成功先例**;篇幅典型 +20–45%,间隔 1–3 年;8/14 改标题且改动精确指向新增轴。
- 政策核实:**ToN 官方无 "30% 新增" 门槛**(原文:"neither a strict guideline … nor a minimum requirement";纯理论补强也算合法增量),硬要求是 cover letter 差异说明 + 引用会议版;ICNP Best Paper 有 ToN fast-track(Plum 不适用,走常规通道;常规案例 GEMINI 修订约 2.5 年,需有心理预期)。
- 两个与我们直接相关的发现:①**Zhuge(SIGCOMM'22→ToN'25)就是本组 Bo Wang/Zili Meng/老师们的扩刊先例**,差异说明与审稿经验可直接内部请教;②精读清单里的 Pudica(ton0066)确认是 NSDI'24 的扩展版,引用/对比时需核对两版。

## 3. Prediction 和 Green 是否构成合理的期刊增量

- **Prediction = "新模块"型**:模块合格,但"用预测"不新;升格路径是补上**失效边界机理 + 扰动界 T1**(变成"新模块+新理论",并握有更稀缺的主张——"预测何时无效")。
- **Green = "新问题维度"型**:改写 problem formulation(QoE→QoE×能耗×热×存活),是比加模块**更实质**的增量;能耗/温度/存活指标在 ICNP 版出现次数为 0,天然满足"结构性新轴"判据。
- **结论:类型上二者都合理,且合起来体量超过典型案例;但当前证据不达样本合格线**(联合实验空白、Green 3 seeds、全线无 CI、无新定理、能耗未校准)。案例中不存在"两个松耦合模块拼一篇"的先例——**统一性(或明确主从)是骨架问题**。

## 4. 推荐的扩刊主线

**门槛化方案 A:4–6 周内用 Pred+Green 联合实验(五对照两平台)做 go/no-go。**
- 增益显著(CI 不重叠)→ **方案 A**:"前瞻式、设备状态感知的双向协调框架"(预测=未来网络状态,SoC/温度=设备状态演化;对标 TACK/FEDL 档的故事升维;标题可取 Zhuge 式系统名入题)。
- 不显著 → **方案 B**:Green 主线("协调不只分带宽,还管设备存活与热稳定",诚实量化 -42% 吞吐换存活翻倍的代价),Prediction 降为带失效边界分析的次要节(呼应 ToN'26 "Accurate is Not Necessarily the Best" 的命题)。
- 两案共用的工作(统计加固/失效边界/能耗校准)现在即可并行开工,不必等判据。

## 5. 下一步优先做什么(排序即优先级)

1. **Pred+Green 联合实验 + 最小耦合机制 D1**(go/no-go,决定论文骨架);
2. **统计加固**:Green 3→≥10 seeds,全部结果补 95% CI;
3. **预测失效边界**:误差注入 + trace-driven 不敏感机理 + 扰动界推导(未推导成功不写定理);
4. **能耗校准**:先修 92°C/20W 模型 artifact(小工作量),再做 ≥1 台真机功率计锚点;
5. **投稿准备**:取得 seq312 全文确认竞争关系;按 ToN 政策准备 cover letter 差异说明;内部请教 Zhuge ToN 扩刊经验。
